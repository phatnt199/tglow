v0.11.1 — tglow has a licence

No code changed. This release exists so that the licence ships with it.

Until now the repository carried none at all: no `LICENSE` file, no `license`
field, and GitHub reported the project as licensed `NONE`. That is not a
missing formality — the default is all rights reserved, so nobody could
legally use or redistribute the binaries this README invites them to
download. It surfaced while filling in a directory submission, where the only
honest answer for the licence field was "unspecified".

tglow is now [MIT](https://github.com/phatnt199/tglow/blob/main/LICENSE),
copyright Phat Nguyen. Use it, change it, ship it; keep the copyright notice.
The licence covers tglow alone — Telegram's own
[Terms of Service](https://telegram.org/tos) still govern what you do with the
account you point it at.

The binaries are built from the same source as v0.11.0 and behave identically.
If you are already on v0.11.0 there is nothing here you need, beyond knowing
what you are allowed to do with it.

Also since v0.11.0, none of it in the binary: the homepage moved to
[tglow.phatnt.com](https://tglow.phatnt.com) and is now published from CI, so
the page and the source in this repository can no longer drift apart the way
they had.
